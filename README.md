# Voice Notes | Premium Dictation

A robust, modern speech-to-text application built with the Web Speech API and Vanilla JavaScript. This project is a refined take on the classic "Speech Detection" exercise, featuring a premium SaaS-style interface, real-time statistics, and voice-activated commands.

![Project Preview](https://via.placeholder.com/860x400.png?text=Voice+Notes+Preview) *(Optional: Replace with your project screenshot)*

## ✨ Features

- **Real-time Transcription:** Uses the Web Speech API for low-latency, accurate speech-to-text conversion.
- **Voice Commands:** 
  - `"New paragraph"` / `"Next paragraph"`: Creates a new block of text.
  - `"Clear screen"` / `"Clear notes"`: Wipes the current transcript.
- **Live Statistics:** Track your progress with real-time word and character counts.
- **Modern UI:** 
  - **Animated Waveform:** Visual feedback showing active listening.
  - **Dark Mode:** A sleek, high-contrast interface designed for focus.
  - **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Export Options:** 
  - **Copy to Clipboard:** Quickly grab your notes with one click.
  - **Download TXT:** Save your transcription as a local text file.
- **Smooth Auto-Scroll:** The editor automatically follows your speech for a seamless experience.

## 🚀 Getting Started

### Prerequisites

- A modern web browser that supports the Web Speech API (Google Chrome or Microsoft Edge recommended).
- A functioning microphone.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/voice-notes.git
   ```
2. Open `index.html` in your browser.

## 🛠️ Built With

- **HTML5:** Semantic structure for the editor and tools.
- **CSS3 (Custom Properties):** Modern styling with CSS variables and Inter font.
- **Vanilla JavaScript:** Core logic for speech recognition and UI interactions.
- **Web Speech API:** Powering the voice recognition engine.

## 📖 How to Use

1. Click **"Start Listening"** (the app usually starts listening automatically on load).
2. Grant microphone permissions if prompted.
3. Start speaking! Your thoughts will appear in the editor.
4. Use voice commands like `"New paragraph"` to organize your text.
5. Use the toolbar to **Copy**, **Download**, or **Clear** your notes.
